Key Rules for Implementation

RuleDetails
Cyan = live signal only Use #00F5D4 ONLY for: "active/connected" badges, live process indicators, real-time data highlights. NOT for buttons, icons, borders, or general accent.
Amber = primary action All primary buttons, focus rings, active tab indicators, and "most important thing on screen" get amber (#D4A030).
Labels: mixed case, sans Replace UPPERCASE TRACKING-WIDER MONO labels with Sentence case, sans-serif, medium weight. Reserve uppercase for true alerts.
Values: mono, white Data values stay mono but are white (#F1F5F9), not colored. Color only means status (green=ok, amber=warn, red=error).
Text floor: 10px No text smaller than 10px. Section headings 12-13px. Card titles 13-14px.
Body gradient: warm Change emerald+blue gradient to amber+slate: rgba(212, 160, 48, 0.03).
