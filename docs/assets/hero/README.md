# Imágenes de portada

Una imagen por fecha, con el nombre `AAAA-MM-DD_tema.jpg`. El `README.md` y el `README.es.md` apuntan a la última. Para rotar: añadir la imagen nueva aquí y cambiar el `src` en los dos README (un solo commit del TL).

Normas:
- Optimizar antes de subir: unos 1600 px de ancho y menos de 500 KB, porque lo que entra en un repositorio público se queda en el historial.
- No sustituir ni borrar el logo de la lechuza de `assets/branding`.
- El texto alternativo describe la escena sin nombrar marcas.

Imágenes actuales:
- `2026-10-29_guardianes.jpg`: ilustración generada con un modelo de difusión (la lechuza y su equipo de agentes). Contiene guiños a marcas de terceros como parte del arte; decisión de José, 2026-10-29.

Vista previa social de GitHub: `social_preview_1280x640.jpg` (2:1, 1280x640, menos de 1 MB). GitHub no permite subirla por API; se carga a mano en Ajustes del repositorio, apartado "Social preview".
